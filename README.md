1. Important Notes
        •--watch keeps the CLI running and rebuilds automatically when files change.
        •input.css is your source file where Tailwind is imported.
        •output.css is auto-generated — do NOT edit it manually.
        •output.css includes:
             •Preflight (CSS reset)
             •Theme variables
             •Utility classes

        •Use npm run build to start the Tailwind CLI in watch mode and automatically rebuild styles whenever changes 
           are detected.
