# npm init -y

Creates a package.json file with default settings for the project

# npm install tailwindcss @tailwindcss/cli

Installs Tailwind CSS and its Command Line Interface (CLI) locally in the project

# npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch

Reads input.css, processes Tailwind CSS, generates output.css, and automatically rebuilds when changes are detected

# input.css

/_ Imports Tailwind CSS into the project _/
@import "tailwindcss";

{
"scripts": {
"build": "npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch"
}
}

# index.html

Connects the generated Tailwind CSS file to the webpage

<!-- <link rel="stylesheet" href="./src/output.css"> -->

!NOTES

1.  --watch : The --watch flag keeps the Tailwind CLI running and automatically regenerates
    output.css whenever changes are detected in your CSS files or files containing
    Tailwind classes.

2.  input.css : serves as the entry point for Tailwind CSS.
    By importing Tailwind using:

@import "tailwindcss";

the CLI can process Tailwind's utilities, components, and base styles and
generate standard CSS inside output.css.

3. Scripts Section : "scripts": {
   "build": "npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch"
   }
   The scripts section allows the Tailwind command to be stored inside
   package.json, making it easier to execute without typing the full command
   every time the project is opened.

4. npm run build : Executes the command associated with the "build" script in package.json and
   starts the Tailwind build process.

5. The output.css file contains the final CSS generated by Tailwind.
   It includes:

- Theme variables
- Preflight (Tailwind's CSS reset)
- Utility classes

Reminder:
output.css is NOT called "Preflight".
Preflight is only one section within the generated output.css file.

6.  Connection
    <!-- <link rel="stylesheet" href="./src/output.css"> -->

    Links the generated CSS file to the HTML document so Tailwind styles can be
    applied to the webpage.

7.  Typical Project Structure
    project/
    │
    ├── package.json
    ├── node_modules/
    │
    ├── public/
    | ├── index.html
    │
    └── src/
    ├── input.css
    └── output.css

    * This structure keeps source files organized and separates the generated CSS from the main HTML file.
